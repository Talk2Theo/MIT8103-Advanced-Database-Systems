
# SQL Implementation Scripts

This directory contains the PostgreSQL SQL and
PL/pgSQL scripts developed for the Theoscyba
Security Services Incident and Vulnerability
Management System.

The scripts implement:

- Relational tables and foreign keys
- Operational demonstration data
- Database integrity constraints
- JSONB audit logging
- Incident assignment history
- Database verification and testing

The execution order and prerequisites are
documented in README_REBUILD.md, which will
be provided in the documentation directory.

Database: PostgreSQL 18
Status: Implementation completed and verified.
