
# Portfolio 1 Technical Documentation

This directory contains the technical
documentation for the Theoscyba Security
Services database project.

Documents include:

- Portfolio 1 technical report
- SQL database rebuild instructions
- Relational schema and normalisation analysis
- Implementation and testing explanations

The report discusses PostgreSQL design,
constraints, JSONB auditing and incident
assignment history.

The rebuild guide documents the correct
script execution sequence and dependencies.
